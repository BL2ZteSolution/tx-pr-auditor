# MW 4.1.3 compatibility

Auditor 1.2.3 explicitly supports shared MW 4.1.3 region-based West Malaysia routing and configurable Northern/Eastern KV packing defaults. Previous 4.1.0–4.1.2 support and DU registry identity remain unchanged. Full Auditor and shared MW integration tests are release gates. This is a dependency-compatibility release, not an audit-rule relaxation.
